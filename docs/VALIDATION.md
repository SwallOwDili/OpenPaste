## 执行方法

在项目根目录：

```sh
./build.sh
./scripts/check.sh
```

检查脚本不调用用户配置的翻译服务，需要 Python 3 和可用的本机 18767 端口。窗口检查另行执行；先退出普通实例，以免快捷键冲突：

```sh
build/OpenPaste.app/Contents/MacOS/OpenPaste --layout-test
```
