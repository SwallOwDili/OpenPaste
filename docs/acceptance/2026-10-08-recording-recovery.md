# 记录故障恢复与普通粘贴验收（2026-10-08）

范围：首次启用与历史读取错误分离、普通粘贴移除旧内容全量读取、保存/读取故障恢复，以及翻译配置验收描述更正。此记录不代表全部产品功能或正式发布验收通过。

## 实现与约束

- 同意或暂不启用只改变记录授权；读取失败、保存失败、用户暂停各自保留。
- 未完整读取原历史时，禁止保存、导入、新建、编辑、删除、收藏等修改；保护原索引和附件。删除动作也不能提前写入撤销栈。
- “重试读取”成功后安装完整历史；“重试保存”成功后清除保存故障。旧目录、旧保存或读取请求的迟到回调不得覆盖当前状态。
- 普通单条、批量、队列复制不读取旧剪贴板内容；写入失败不消费队列、不重排历史、不发送自动粘贴。系统已经清空剪贴板后发生写入失败，不保证恢复旧内容。
- 选区翻译的临时复制继续保留完整快照和版本检查，恢复时不覆盖外部新内容。
- 翻译 API Key 与其他翻译设置共同保存在应用偏好 plist；不再以“不存在于 UserDefaults”为通过条件，不使用钥匙串或独立 JSON。
