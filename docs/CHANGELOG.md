# Changelog

项目仍处于试用阶段，以下版本已在开发机构建，不表示已发布 GitHub Release。

## 0.5.4

- 菜单及关于页面增加 GitHub 正式 Release 检查、新版提示与下载入口。
- 自动检查默认关闭，开启后按 24 小时间隔检查；自动失败不弹窗。
- 支持更新说明、跳过版本和缓存；安装包未上传时暂不提示下载。

## 0.5.3

- 点击外部窗口时收起剪贴板卡片，并重置临时反向排序。
- 增加失焦关闭路径；预览、编辑和确认弹窗期间保留卡片。

## 0.5.2

- 设置增加“关于 OpenPaste”，展示应用信息、版本、功能与授权原则。
- 内置 GPL v3 英文原文、中文参考译文及中英文署名条款。
- 更新菜单栏图标；README 增加演示截图。

## 0.5.1

- 翻译 Base URL 支持远程 HTTP。
- 保留 URL 格式校验和重定向限制。

## 0.5.0

- 应用 ID、钥匙串服务、资源、缓存、拖放类型与默认目录统一为 OpenPaste。
- 应用 ID 改变，辅助功能权限可能需要重新授权。

## 0.4.1

- 设置使用普通窗口层级，切换应用后不再置顶。

## 0.4.0

- 支持选择保存目录，后台迁移历史与附件并显示进度。
- 支持选择 iCloud Drive 文件夹，添加设备独立索引、版本合并、删除标记和本机离线缓存。

## 0.3.x

- 设置改为通用、快速翻译、隐私与权限、数据管理四个页面。
- 修复设置与待选列表的窗口和关闭行为。

## 0.2.x

- 应用更名为 OpenPaste。
- 添加网页、Apple 地图、颜色和代码预览。
- 添加编辑、重命名、OCR、图片处理、多选和批量操作。
- 添加 OpenAI 兼容的选中文字快速翻译，以及代码富文本取用。

## 0.1.x

- 建立本机剪贴板记录、横向卡片、搜索、收藏与键盘操作。
- 添加 Paste 导入、容量处理、进度显示和备份。
